# Cloudflare Pages Build Configuration for Next.js with OpenNext

## ⚠️ Important: This project uses OpenNext, not @cloudflare/next-on-pages

The old `@cloudflare/next-on-pages` adapter is **deprecated**. This project is configured to use **OpenNext** which is the recommended and officially supported approach for deploying Next.js to Cloudflare Pages.

## Cloudflare Pages Settings

Update your Cloudflare Pages project settings with the following:

### Build Configuration
- **Framework preset**: `Next.js`
- **Build command**: 
  ```bash
  npx opennextjs-cloudflare build
  ```
- **Build output directory**: 
  ```
  .open-next/assets
  ```

### Root Directory
- Leave as default (project root)

### Environment Variables
Make sure all your environment variables are configured in the Cloudflare Pages dashboard. Required variables include:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `DISCORD_WEBHOOK_URL`
- `DISCORD_NEW_USER_WEBHOOK_URL`
- `RESEND_API_KEY`
- `NEXT_PUBLIC_APP_URL`

## Project Configuration Files

The project includes these configuration files for Cloudflare deployment:
- `open-next.config.ts` - OpenNext configuration
- `wrangler.jsonc` - Cloudflare Workers configuration
- `package.json` - Includes deploy script: `npm run deploy`

## Local Testing

To test the build locally:
```bash
npm run build  # Builds Next.js
npx opennextjs-cloudflare build  # Builds for Cloudflare
npx wrangler pages dev .open-next/assets  # Test locally
```

## Deployment

The project can be deployed via:
1. **Cloudflare Pages Git integration** (recommended)
   - Push to your connected repository
   - Cloudflare Pages will automatically build and deploy
   
2. **Manual deployment**:
   ```bash
   npm run deploy
   ```

## Key Differences from @cloudflare/next-on-pages

- **No need for edge runtime exports** - OpenNext handles the conversion automatically
- **Full Next.js API support** - All Next.js features work without special configuration
- **Better performance** - Optimized specifically for Cloudflare's infrastructure
- **Active maintenance** - OpenNext is actively maintained and recommended by both Next.js and Cloudflare teams

## Troubleshooting

If you encounter build errors:
1. Clear the build cache in Cloudflare Pages
2. Ensure all environment variables are set
3. Verify Node.js version (should be 18.x or later)
4. Check that the build command is exactly `npx opennextjs-cloudflare build`
